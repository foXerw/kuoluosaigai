# kuoluosaigai 组织图标（org icon）设计

日期：2026-06-29
状态：已批准

## 背景

用户在 GitHub 上创建了同名组织 `kuoluosaigai`，计划将其发展光大，未来可能把当前 web 应用仓库迁入该组织。需要一个可手动上传作为 GitHub 组织头像的图标。

约束：
- 文件放在 `public/` 下，当前应用**不会**引用它，仅作为组织头像资源。
- 现有 `public/favicon.svg`（终端风 K 字徽）保持不动。
- 这是**组织级品牌徽**，不是项目徽，因此不复用 K 字。

## 名字含义

`kuoluosaigai` 谐音"这个世界"。组织徽需表达"这个世界"的意象，同时符合组织品牌身份。

站点起源是致敬《无头骑士异闻录》Dollars 匿名聊天室的"频道接入页"——即一个**进入某个世界的传送门**。这给出了统一概念：**世界 + 传送门**。

## 设计方向

选定方案 **A — Portal World**：一个世界（圆环）顶部开口形成传送门，开口处一颗终端绿圆点作为"这个世界"的标记 / 传送门钥匙。

不使用任何字母，作为真正的组织级品牌徽。

### 备选（未采用）

- B Meridian Globe：圆球 + 经线，一条经线终端绿。小尺寸偏密、偏通用。
- C Horizon Sunrise：半圆 + 地平线。诗意不对称，方形头像里不好平衡。

## 规格（64×64 viewBox）

- **徽章底**：圆角方形，`x=3 y=3 w=58 h=58 rx=11`，填充 `#0a0e0a`（近黑，与 favicon 一致），描边 `#39ff14` @ 不透明度 ~0.22、宽度 2（与终端起源的微弱呼应，非强提示）。
- **世界环**：描边圆环（非填充），圆心 (32,32)、半径 19、描边 `#e8e8e8`、宽度 3.5、`stroke-linecap: round`，顶部留约 40° 缺口 = 传送门开口。用 arc path 实现：`M 25.5 14.1 A 19 19 0 1 1 38.5 14.1`（从左上点顺时针长弧到右上点，顶部留缺口）。
- **绿色珍珠**：实心圆，圆心 (32, 13.5)、半径 3.5、填充 `#39ff14`，嵌于顶部缺口处。全图唯一饱和绿，承担"这个世界"标记。

## 配色

| 角色 | 色值 |
|---|---|
| 徽章底 | `#0a0e0a` |
| 世界环 | `#e8e8e8` |
| 强调（唯一） | `#39ff14` |

三色、一强调，16px 仍可辨。

## 适配性

徽章自带深色底，自包含；在 GitHub 浅色导航与深色背景下均能正确呈现，不依赖透明背景。

## 产出

- `public/org-icon.svg`（应用不引用；用户手动上传至 GitHub 组织）。
- `public/favicon.svg` 保持不变。
