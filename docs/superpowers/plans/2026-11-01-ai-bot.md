# 个人 AI Bot（BOT DECK）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 纯浏览器层的个人 AI bot 系统——用户配置 OpenAI 兼容 provider 与人格档案，≤5 个 bot 以独立 WS 连接进房拟人聊天（互聊/回真人/冷场主动发起），BOT DECK 面板管理启停/切房/用量/观战，服务器零改动。

**Architecture:** `src/bots/` 纯 ESM 模块层（buffer/rhythm/prompt/llm/connection/lease/runner/store）+ 两个终端风 Vue 组件（BotDeck/BotCard）。store 为 App 层 Vue reactive 单例，runner 每 bot 一个、与人类 useChat/roomCache 零交叉。所有随机/时间/IO 依赖注入（rng/now/sleep/WebSocketImpl/fetchImpl/storage）保证可测。

**Tech Stack:** Vue 3（Options API 组件 + reactive store）、原生 fetch + AbortController、原生 WebSocket、vitest + @vue/test-utils + jsdom。零新增运行时依赖。

**Spec:** `docs/superpowers/specs/2026-11-01-ai-bot-design.md`（§7 参数表、§8 架构、§9 边界 B1~B21、§11 测试策略——执行时两个文档都要读）

## Global Constraints

- 服务器零改动；协议护栏沿用多房间轮：发言 ≤10 条/分/连接、单条 ≤280 字（客户端先自截）、`ANON-XXXX` 昵称格式、badge 自报
- 零新增 npm 运行时依赖；AI 调用只用原生 fetch
- 测试基线 182（143 客户端 + 39 服务端）只增不减；`npm test` 全绿是每任务提交前提
- localStorage 键名固定：配置 `kuoluosaigai:bots:v1`、租约 `kuoluosaigai:bots:lease`；人类昵称沿用 `kuoluosaigai:nick`（sessionStorage）
- badge 格式固定：`BOT·<人格名>`，人格名 ≤12 字符（超长截断）
- apiKey 只允许出现在 fetch 的 Authorization 头；禁止进入 console、error 文案、UI 回显（B9）
- 节奏参数以 spec §7 为准，本计划钉死的具体值：见 Task 2 的 `RHYTHM_DEFAULTS`
- 每任务一个 commit，信息格式沿用仓库惯例（`feat(bots): ...` / `test: ...`），尾行 `Co-Authored-By: Claude Code <noreply@anthropic.com>`

## Review Focus

1. **切房时在途 LLM 响应**（B7）：响应回来时 bot 已切房 → 必须作废不发。Task 7 测试钉死。
2. **apiKey 泄漏**（B9/A3）：任何错误对象、日志、UI 不得含 key。Task 4 断言 error.message/序列化不含 key；Task 9 断言输入不回显。
3. **双标签同点启动竞态**（B20）：写后复查确认租约归本 tab。Task 6 测试钉死。
4. **跨房 history-res 污染**：bot 秒切房后旧房迟到响应不得进缓冲。Task 7 测试钉死。
5. **配置损坏/配额满**（B15/B17）：坏 JSON 静默重建、写失败降级仅内存 + 黄条，绝不白屏。Task 8 测试钉死。

**钉死常量（= spec §7，写进 RHYTHM_DEFAULTS）：**

```js
export const RHYTHM_DEFAULTS = {
  replyBase: { mention: 0.9, owner: 0.7, human: 0.4, bot: 0.2 }, // isSelf 由调用方先滤，不进 decide
  thinkMs: [2000, 8000],
  typingMsPer50: [1000, 2000], totalDelayCapMs: 15000,
  streakLimit: [6, 10],        // 每次 streak 归零时重掷
  cooldownMs: [30000, 120000],
  hourlyCap: 30,               // 超限只回 mentions
  minGapMs: 8000,
  afkRollProb: 0.15, afkMs: [300000, 1200000],   // 冷却结束/闲置重新武装时掷
  idleBaseProb: 0.3,
  idleWindowAfterChatMs: [180000, 480000],       // 3~8min
  idleWindowAfterIdleMs: [480000, 900000],       // 8~15min
  idleCheckMs: 15000,
}
// 话痨度系数（设计者裁定）：factor = 0.2 + 1.6 * (chattiness / 100)，最终概率 clamp [0,1]
// chattiness 50 = 1.0x 基准；0 = 0.2x（不完全闭嘴）；100 = 1.8x
```
